# Snackyzz Web Mockup Design

## Goal
Create a polished web-only mockup for Snackyzz, a playful premium cookie brand with soft colors. The mockup should show how customers can buy cookies, find sales points, and learn about the brand.

## Pages
- Home: brand-forward hero, featured cookies, quick paths to shop and sales points, and a short quality/story preview.
- Shop: cookie product grid with prices, flavor tags, quantity controls, and a mock order summary.
- Sales Points: location finder with city filters, store cards, hours, and a map-style visual panel.
- About/Info: brand story, ingredients/quality notes, FAQs, and contact/social details.

## Visual Direction
Snackyzz should feel colorful, fun, and polished. Use a soft cream base with strawberry pink, butter yellow, mint, and chocolate accents. The product visuals should be appetizing and prominent. Cards should stay tidy with small border radii, strong spacing, and clear calls to action.

## Interaction Scope
The mockup is static but should feel real: navigation moves between sections/pages, quantity buttons are present as controls, sales point filters are visible, and the cart summary communicates the intended buying flow. No backend, payment, account system, or real map integration is included.

## Verification
Use a lightweight smoke test to confirm all four pages/sections and main navigation labels exist. Run a local server and inspect the mockup in the browser after implementation.
